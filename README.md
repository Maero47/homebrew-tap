# Maero47 Homebrew tap

```sh
brew install maero47/tap/portlight-host
portlight-host install
```

`portlight-host` is the native helper for [Portlight](https://github.com/Maero47/portlight), a Chrome extension that shows which localhost ports are in use and which are free. After installing, run `portlight-host install` once to register the helper with your browsers.
